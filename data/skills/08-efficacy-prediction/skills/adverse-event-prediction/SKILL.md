# 不良反应预测评分

预测不良反应并绘图。

## 执行流程
1. 输入：患者概况+选定治疗方案
2. 分析方案中各药物已知不良反应谱
3. 结合患者特征预测各不良反应发生概率
4. 绘图：1种不良反应1张图（横坐标=生存时间，纵坐标=各等级不良反应发生率）
5. 输出：不良反应预测评分+系列图表

## 输出规范

- 禁止输出 ASCII 曲线、字符热力图或分号堆叠图表。
- 必须输出结构化 `adverse_prediction`：`name`、`labels`、`grade1`、`grade2`、`grade3`、`monitoring`、`management`。
- “各不良反应预测概率（≥Grade 3）”必须同时输出表格：不良反应、预测概率、风险等级、监测建议、处理建议。
- 热力图无法真实渲染时，降级为矩阵表：不良反应、各时间点严重程度、等级说明。
