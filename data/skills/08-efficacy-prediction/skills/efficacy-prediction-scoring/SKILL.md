# 疗效预测评分

预测治疗效果并绘制肿瘤大小变化曲线。

## 执行流程
1. 输入：患者概况+选定治疗方案
2. 基于预测模型或专家规则进行疗效预测评分
3. 绘图：横坐标=生存时间，纵坐标=不同病灶的肿瘤大小（每条曲线表示1个病灶）
4. 输出：疗效预测评分+肿瘤大小变化曲线图

## 输出规范

- 禁止输出 ASCII 曲线、字符折线图或 `●`、`\`、`│` 等文本图。
- 必须输出结构化 `tumor_prediction`：`labels`、`series[{name, values}]`，单位默认 mm。
- 肿瘤最大径、肿瘤标志物和肺功能趋势若缺少可绘图数据，必须降级为表格：时间点、指标、数值、单位、变化趋势、临床解释。
- 图表标题、单位、图例和趋势说明分开输出，避免写成一整段。
