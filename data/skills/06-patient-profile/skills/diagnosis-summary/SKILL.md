# 诊断总结

综合所有评估结果输出诊断总结。

## 执行流程
1. 输入：肿瘤负荷评估、疗效评估、不良反应评估、合并症评估、ECOG评分
2. 汇总：肿瘤诊断（TNM分期+临床分期+分子分型）
3. 汇总：不良反应诊断（类型+等级）
4. 汇总：合并症诊断
5. 附加：ECOG评分描述、既往基因检测结果（表格）、历史治疗方案（表格）
6. 输出：完整的诊断总结报告
