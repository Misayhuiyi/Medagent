# 不良反应评估

依据RAG检索到的CTCAE 6.0及临床指南、专家共识评估不良反应。

## 执行流程
1. 输入：
   （1）症状记录、体征检查、辅助检查结果
   （2）父Skill传入的RAG检索结果（CTCAE不良反应分级标准片段）
2. 提取不良反应相关信息
3. 遍历RAG检索到的CTCAE标准，评估每种不良反应的等级
4. 参考依据：RAG检索到的临床指南、专家共识、药物临床试验
5. 输出：不良反应评估表（症状-等级-RAG依据来源）
6. 初诊未治疗者跳过，仅评估非治疗相关的合并症状
