# 模型训练

执行疗效预测/不良反应预测/预后预测模型的训练。

## 执行流程
1. 输入：三个标准化训练数据集
2. 疗效预测模型训练：特征=患者概况+治疗方案，标签=实际治疗效果
3. 不良反应预测模型训练：特征=患者概况+治疗方案，标签=实际不良反应
4. 预后预测模型训练：特征=患者概况+治疗方案，标签=实际预后情况
5. 模型评估（验证集指标）
6. 模型保存和部署
7. 输出：三个训练好的预测模型+训练评估报告
