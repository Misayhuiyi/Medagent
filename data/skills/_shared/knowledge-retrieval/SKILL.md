# 知识库检索（RAG）

共享子Skill。为肺癌医生Agent的各评估环节提供循证知识支持。
基于 folder-rag 技术，从已构建的肺癌知识库（121份PDF，29,013个文档块）中检索最相关的临床指南、专家共识等资料。

## 知识库内容

| 类别 | 内容 | 文件数 |
|------|------|--------|
| 临床指南 | CSCO肺癌诊疗指南、NCCN指南（NSCLC/SCLC） | 20+ |
| 专家共识 | 中国肺癌专家共识、不良反应管理共识 | 30+ |
| 分期标准 | TNM第九版分期、iRECIST标准 | 5+ |
| 不良反应 | CTCAE 6.0标准、irAE管理 | 10+ |
| 诊疗规范 | 肺癌诊疗规范、基因检测共识 | 20+ |
| 其他 | 护理指南、康复指导、临床研究 | 30+ |

## 执行流程

### 1、输入

（1）查询问题（query）：明确的临床问题
（2）可选参数：检索数量（top_k，默认5）、查询模式（mode，默认retrieve）

### 2、步骤说明

#### 步骤1：构建RAG查询命令

根据查询问题构建 `exec` 调用命令：

```bash
exec_command = f'python "skills/folder-rag/scripts/rag_query.py" --query "{query}" --mode retrieve --db_path "skills/folder-rag/database/chroma_db" --top_k {top_k}'
```

#### 步骤2：执行RAG查询

使用 `exec` 工具执行上述命令，工作目录为 `\\Steven\Agent\OpenClaw\workspace`：
- 注意：若 RAG 脚本路径或数据库路径不在当前工作目录，使用绝对路径 `\\Steven\Agent\OpenClaw\workspace\skills\folder-rag\scripts\rag_query.py`
- 数据库路径：`\\Steven\Agent\OpenClaw\workspace\skills\folder-rag\database\chroma_db`

#### 步骤3：解析查询结果

从 `exec` 输出中提取相关文档片段，每个结果包含：
- 来源文件名称
- 内容片段
- 相关度分数

#### 步骤4：将结果注入当前评估环节

- 将检索到的知识片段作为当前评估步骤的循证依据
- 在评估结果中标注引用来源

### 3、规范的输出

```json
{
  "query": "2025年CSCO指南对NSCLC一线治疗推荐",
  "results": [
    {
      "source": "2025_CSCO_NSCLC.pdf",
      "content": "对于无驱动基因改变的IV期NSCLC患者...",
      "relevance": 0.892
    }
  ],
  "summary": "根据检索到的知识，CSCO 2025指南推荐..."
}
```

## 错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| RAG脚本未找到 | 尝试使用绝对路径查询 |
| 数据库不存在 | 提示先执行 folder-rag 的索引构建 |
| 查询返回空结果 | 调整查询词，使用同义表达重试 |
| exec执行超时 | 减少 top_k 或拆分查询 |

## 规则

### 1、禁止行为
（1）禁止将查询结果直接作为最终判断——必须结合患者具体资料进行人工/AI分析
（2）禁止引用不在检索结果中的知识

### 2、约束条件
（1）查询内容必须是具体的临床问题，不能是模糊描述
（2）检索结果必须标注来源文件名称
（3）不同评估环节应使用不同的查询问题，避免一次查询解决所有问题
