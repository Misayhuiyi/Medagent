# 就诊时间分析

肺癌医生Agent循环次数确定流程的第一步。负责读取患者主文件夹，列举所有就诊时间子文件夹，按时间先后排序，统计就诊次数。

## 执行流程

### 1、标准的输入

（1）患者文件夹路径（字符串）
（2）就诊时间命名规则（默认：`YYYY-MM-DD` 格式的文件夹名称）

### 2、步骤说明

#### 步骤1：列举患者文件夹下的子文件夹

- 读取患者主文件夹下的所有子文件夹
- 过滤出符合日期格式的文件夹名称
- 如果文件夹名称不符合日期格式但内容与就诊相关，标记为「非标准日期格式」并加入列表

#### 步骤2：排序和统计

- 将符合日期格式的文件夹按日期升序排列（最早→最晚）
- 统计就诊时间总数
- 生成索引编号（从1开始）

#### 步骤3：就诊周期归约（重要）

**将相近日期的就诊合并为住院周期，避免循环次数过多：**

- 扫描所有就诊时间，识别「入院记录」和「出院记录」的配对关系
- 归约规则：
  - 同一入院~出院范围内的所有日期 → 合并为一个住院周期
  - 相邻且间隔≤3天的门诊日期 → 合并为一个门诊周期
  - 间隔>3天的独立检查 → 单独作为一个就诊事件
  - 无住院周期的独立检查日 → 按单日就诊处理
- 输出归约后的就诊周期列表（替换原始的每日列表）
- 示例：2023-12-05至2023-12-11内的10个文件 → 合并为1个住院周期

#### 步骤4：检查特殊条件

- 检查是否存在名为「就诊时间未知」的文件夹
- 检查是否所有就诊周期都有资料内容（非空）
- 标记空周期

#### 步骤5：输出分析结果

- 输出排序后的就诊时间列表和分析结果

### 3、条件判断

| 条件 | 处理方式 |
|------|----------|
| 文件夹名为标准日期格式 `YYYY-MM-DD` | 按日期解析并排序 |
| 文件夹名为 `YYYYMMDD` 格式 | 转换为 `YYYY-MM-DD` 后排序 |
| 文件夹名包含日期但不能解析 | 尝试从名称中提取日期信息 |
| 文件夹名完全不是日期格式 | 标记为「非标准」，按字符串排序 |
| 有同名文件夹 | 按创建时间区分，添加后缀 |

### 4、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 患者文件夹下无任何子文件夹 | 返回空列表，循环次数=0 |
| 患者文件夹路径不存在 | 返回错误「路径不存在」|
| 所有文件夹名称均非日期格式 | 按字符串自然顺序排序，标记所有文件夹 |
| 权限不足无法读取文件夹 | 提示用户检查权限 |

### 5、规范的输出

```json
{
  "patientFolderPath": "本地患者库/张三_001/",
  "visitDates": [
    {"index": 1, "date": "2026-01-15", "isStandard": true, "hasContent": true},
    {"index": 2, "date": "2026-03-20", "isStandard": true, "hasContent": true},
    {"index": 3, "date": "2026-05-10", "isStandard": true, "hasContent": false}
  ],
  "totalVisits": 3,
  "nonStandardFolders": [],
  "emptyFolders": ["2026-05-10"],
  "analysisNotes": "2026-05-10 文件夹内容为空"
}
```

## 规则

### 1、被禁止的行为

（1）禁止在排序过程中修改文件夹名称
（2）禁止跳过空文件夹的统计（空文件夹也算一次就诊记录）

### 2、约束条件

（1）排序必须按时间先后升序（最早排最前）
（2）索引必须从1开始连续编号
（3）每个就诊时间必须标记是否含有内容

### 3、鼓励的行为

（1）对于相近日期的就诊（<3天间隔），标注为「可能为同一就诊周期的多次检查」
（2）记录分析过程的详细日志
