# 循环次数确定

肺癌医生Agent应用层的第三个执行步骤。负责分析患者就诊时间文件夹数量，确定AI问诊循环次数，并为每次循环建立完整的输入输出映射关系，包括既往AI问诊输入、既往AI问诊输出、符合医生规范的结果（医生或AI编辑后）和当前AI问诊输入。

## 执行流程

### 1、标准的输入

（1）02-资料预处理的输出：患者文件夹路径、患者信息JSON、MD文件路径列表
（2）患者信息JSON中的就诊时间列表
（3）各就诊时间文件夹下的资料内容（MD文件）

### 2、步骤说明

#### 步骤1：分析就诊时间文件夹数量

创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/visit-time-analysis/SKILL.md`：
- 读取患者主文件夹，列举所有就诊时间子文件夹
- 按时间先后排序
- 统计就诊时间数量
- 输出：就诊时间列表（已排序）、就诊次数

#### 步骤2：确定循环次数

- 循环次数 = 就诊时间文件夹数量
- 每个就诊时间文件夹对应一次AI问诊循环
- 如果就诊次数为0，提示错误「无可用的就诊时间记录」

#### 步骤3：建立每次循环的输入输出映射关系

创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/io-mapping/SKILL.md`：
- 对每次循环，确定输入输出映射关系：
  - **第1次循环**（最早就诊时间）：输入 = 该就诊时间的资料MD文件；输出 = AI问诊结果
  - **第N次循环**（N>1）：输入 = 既往所有AI问诊输入 + 既往所有AI问诊输出 + 符合医生规范的结果 + 当前就诊资料MD文件
- 每次循环以最新就诊时间前的「出院记录」（医生诊疗文件夹下）进行AI编辑
- 输出：每次循环的完整映射关系表

#### 步骤4：确定当前循环索引

- 当前执行的是哪一次循环（从1开始计数）
- 如果是新增患者问诊记录，既往AI问诊应包括该患者所有历史问诊信息

### 3、条件判断

| 条件 | 处理方式 |
|------|----------|
| 只有一个就诊时间文件夹 | 循环次数=1，第1次循环仅使用该次就诊资料 |
| 多个就诊时间文件夹 | 循环次数=就诊次数，每次循环含既往信息 |
| 就诊时间文件夹为0 | 报错「无可用的就诊时间记录」，终止后续流程 |
| 某就诊时间下无「医生诊疗」文件夹 | 无出院记录可编辑，跳过AI编辑步骤 |
| 本次为新增患者问诊记录 | 既往AI问诊需包含该患者所有历史问诊信息 |

### 4、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 患者文件夹路径不存在 | 提示路径错误，检查02-资料预处理输出 |
| 就诊时间文件夹名称不符合日期格式 | 按名称字符串排序，标记不规范名称 |
| 某就诊时间文件夹为空（无资料）| 跳过该次循环，记录为空 |
| 无出院记录 | 输出「无出院记录」，继续执行其他步骤 |

## 规则

### 1、被禁止的行为

（1）禁止跳过就诊时间分析直接设定循环次数
（2）禁止在多次循环场景中忽略既往AI问诊输入输出
（3）禁止合并不同就诊时间的历史资料为单次输入

### 2、约束条件

（1）循环次数必须等于就诊时间文件夹数量
（2）每次循环的当前输入必须是该次就诊时间的资料MD文件
（3）第N次循环的输入必须包含第1到N-1次的所有相关信息
（4）出院记录编辑必须使用本次就诊时间前的最新出院记录

### 3、鼓励的行为

（1）对于多次就诊的历史记录，精简去重后再提供给AI问诊
（2）在映射关系中标记哪些是医生编辑后的结果（提高输入质量）
（3）对于时间跨度大的多次就诊，标注时间间隔信息
