# 患者检查：姓名校验问题

## 现象
患者文件夹名为"张三"，但医疗文件内姓名均为"刘海平"，导致患者检查时无法匹配。

## 原因分析
原设计假设文件夹名即为患者真实姓名，未验证医疗文件内姓名的一致性。

## 修复方案
1. 患者检查时，同时读取入院记录等医疗文件中的姓名
2. 以医疗文件中的姓名为真实姓名
3. 文件夹名仅用于查找，姓名校验以文件内容为准
4. 如发现不一致，记录到对应关系表并提示用户
