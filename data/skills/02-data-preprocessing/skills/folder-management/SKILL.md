# 文件夹管理

肺癌医生Agent资料预处理流程的第二步。根据患者检查结果执行对应的文件夹操作：新患者创建完整结构，老患者创建新就诊时间文件夹。

## 执行流程

### 1、标准的输入

（1）患者检查结果（isNewPatient标识 + 患者信息）
（2）结构化资料目录JSON（来自01-资料整理）
（3）本地患者库根路径（默认：`本地患者库/`）

### 2、步骤说明

#### 子流程A：新患者文件夹创建

##### 步骤A1：创建患者主文件夹
- 路径格式：`{本地患者库根路径}/{患者姓名}_{门诊号}/`
- 如果文件夹已存在，检查是否为旧记录残留，确认后使用

##### 步骤A2：填写患者信息表
- 创建 `患者信息.json` 到患者主文件夹
- 字段：姓名、门诊号、性别、年龄、首次就诊时间、已就诊次数（1）

##### 步骤A3：创建就诊时间文件夹
- 路径格式：`{患者主文件夹}/{就诊时间1}/`
- 在就诊时间文件夹下按5种资料类型创建子文件夹：
  - `影像报告/`
  - `病理报告/`
  - `检验报告/`
  - `病历/`
  - `医生诊疗/`

##### 步骤A4：创建/更新对应关系表
- 如果 `患者-AI医生对应关系表.json` 不存在，创建新表
- 如果存在，追加当前患者记录
- 记录格式：`{ "门诊号": "...", "姓名": "...", "文件夹路径": "...", "就诊时间": [...] }`

#### 子流程B：老患者文件夹更新

##### 步骤B1：查找现有患者文件夹
- 根据患者检查结果中的 `existingInfo.folderPath` 定位
- 验证文件夹存在且内容完整

##### 步骤B2：更新患者信息表
- 读取已有 `患者信息.json`
- 新增就诊时间到就诊时间列表
- 已就诊次数 +1
- 写回 `患者信息.json`

##### 步骤B3：创建新就诊时间文件夹
- 路径格式：`{患者主文件夹}/{新就诊时间}/`
- 在新就诊时间文件夹下按5种资料类型创建子文件夹

##### 步骤B4：更新对应关系表
- 追加新就诊时间到对应关系表的就诊时间列表

### 3、条件判断

| 条件 | 处理方式 |
|------|----------|
| 患者主文件夹已存在（新患者场景） | 检查内容，如为空则复用，否则提示手动处理 |
| 就诊时间文件夹已存在 | 检查是否有新资料，如有则覆盖，否则跳过 |
| 患者信息.json 已存在但缺少字段 | 补充缺失字段 |
| 创建文件夹时权限不足 | 提示用户检查权限并手动创建 |

### 4、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 路径包含非法字符 | 替换非法字符为下划线 |
| 文件夹创建失败 | 尝试创建设置中指定的备用路径 |
| 磁盘空间不足 | 提示用户释放空间或更换存储位置 |
| 文件夹名称冲突 | 使用后缀数字避免冲突（如 `张三_001_1`）|

### 5、规范的输出

```json
{
  "status": "success",
  "patientFolderPath": "本地患者库/张三_001/",
  "visitFolderPath": "本地患者库/张三_001/2026-01-15/",
  "patientInfo": { ... },
  "folderStructure": {
    "影像报告": "本地患者库/张三_001/2026-01-15/影像报告/",
    "病理报告": "...",
    "检验报告": "...",
    "病历": "...",
    "医生诊疗": "..."
  },
  "processLog": "2026-01-15 10:00:00 - 创建患者主文件夹成功\n2026-01-15 10:00:01 - 创建就诊时间文件夹成功"

```

## 规则

### 1、被禁止的行为

（1）禁止跨患者混用文件夹
（2）禁止删除或修改老患者的已有资料
（3）禁止在就诊时间文件夹外存放患者资料

### 2、约束条件

（1）患者主文件夹命名必须是 `{患者姓名}_{门诊号}` 格式
（2）就诊时间文件夹命名必须使用 `YYYY-MM-DD` 格式
（3）资料类型子文件夹必须包含全部5种标准类型（可为空）
（4）每次操作必须更新 `患者信息.json` 和对应关系表

### 3、鼓励的行为

（1）创建文件夹后验证目录结构完整性
（2）在日志中记录所有创建/更新操作的详细信息
（3）对长时间未操作的患者文件夹标记为「归档」状态

## 工具声明（tools）

### 1、可以使用的工具、Skill等

| 工具名称 | 链接或访问方式 | 说明 | 适用场景 |
|----------|----------------|------|----------|
| exec | 内置工具 | 创建文件夹、检查路径是否存在 | 文件系统操作 |
| write | 内置工具 | 写入患者信息JSON和对应关系表 | 数据写入 |
| read | 内置工具 | 读取已有患者信息 | 更新操作 |

### 2、不可使用的工具

（1）禁止使用 rm/Remove-Item 删除除临时文件外的任何内容
（2）禁止修改原始上传资料文件
