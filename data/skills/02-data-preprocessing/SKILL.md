# 资料预处理

肺癌医生Agent应用层的第二个执行步骤。负责检查患者是否为新患者或老患者，完成患者信息登记、文件夹结构创建/更新、以及PDF格式资料到MD格式的转换，为后续AI问诊做准备。

## 执行流程

### 1、标准的输入

（1）01-资料整理的输出：结构化资料目录JSON
```json
{
  "就诊时间1": {
    "影像报告": ["文件1", "文件2"],
    "病理报告": ["文件3"],
    "检验报告": ["文件4", "文件5"],
    "病历": ["文件6"],
    "医生诊疗": []
  }
}
```
（2）患者基本信息（姓名、门诊号、性别、年龄）

### 2、步骤说明

#### 步骤1：检查患者是否已使用过AI医生

创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/patient-check/SKILL.md`：
- 根据患者姓名、门诊号查询患者—AI医生对应关系表
- 判断患者是否已使用过AI医生
- 输出：检查结果（新患者/老患者）+ 已有患者信息（如存在）

#### 步骤2：根据检查结果执行分支操作

**分支A：新患者（未使用过AI医生）**

创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/folder-management/SKILL.md` 子流程A：
- 填写患者信息表（姓名、门诊号、性别、年龄、首次就诊时间）
- 创建患者主文件夹：`本地患者库/{患者姓名}_{门诊号}/`
- 在患者主文件夹下创建首个就诊时间文件夹：`{就诊时间1}/`
- 在就诊时间文件夹下按5种资料类型创建子文件夹
- 将患者信息写入 `患者信息.json`
- 将对应关系写入 `患者-AI医生对应关系表.json`
- 输出：本地患者库路径、患者信息JSON

**分支B：老患者（已使用过AI医生）**

创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/folder-management/SKILL.md` 子流程B：
- 查找现有患者文件夹路径
- 更新患者信息表（新增就诊时间）
- 创建新就诊时间文件夹：`{新就诊时间}/`
- 在新就诊时间文件夹下按5种资料类型创建子文件夹
- 更新 `患者-AI医生对应关系表.json`（如有需要）
- 输出：本地患者库路径、患者信息JSON

#### 步骤3：PDF资料转换为MD格式

创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/pdf-conversion/SKILL.md`：
- 遍历当前就诊时间下各资料类型文件夹中的所有PDF文件
- 将每个PDF文件转换为MD格式
- 转换后的MD文件保存到对应资料类型文件夹中
- 输出：转换后的MD文件路径列表

#### 步骤4：输出汇总

- 汇总本地患者库路径、患者信息、MD文件路径列表
- 输出到标准输出，供下一个Skill（循环次数确定）使用

### 3、条件判断

| 条件 | 处理方式 |
|------|----------|
| 患者从未使用过AI医生 | 走分支A（新患者流程） |
| 患者已使用过AI医生 | 走分支B（老患者流程） |
| 当前就诊时间文件夹下无PDF文件 | 跳过PDF转换步骤，输出空列表 |
| PDF文件内容为空或无法解析 | 标记为「转换失败」，继续处理其他文件 |
| 患者信息中缺少必要字段 | 提示用户补充完整信息 |

### 4、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 患者—AI医生对应关系表不存在 | 按新患者处理，创建对应关系表 |
| 患者文件夹已存在但无对应关系记录 | 按老患者处理，修复对应关系表 |
| PDF文件损坏无法转换 | 跳过该文件，在转换日志中标记 |
| 权限不足无法创建文件夹 | 提示用户检查目录权限 |
| 磁盘空间不足 | 提示用户释放空间 |

### 5、规范的输出

（1）本地患者库路径（字符串）
（2）患者信息JSON（含姓名、门诊号、性别、年龄、就诊时间列表）
（3）资料预处理后的MD文件路径列表（数组）
（4）预处理日志（记录所有操作和异常情况）

```json
{
  "patientLibPath": "本地患者库/张三_001/",
  "patientInfo": {
    "name": "张三",
    "clinicId": "001",
    "gender": "男",
    "age": 65,
    "firstVisit": "2026-01-15",
    "visitDates": ["2026-01-15"]
  },
  "mdFiles": [
    "本地患者库/张三_001/2026-01-15/影像报告/CT报告.md",
    "本地患者库/张三_001/2026-01-15/病理报告/病理报告.md"
  ],
  "processLog": "2026-01-15 10:00:00 - 新患者，创建文件夹完毕\n2026-01-15 10:01:00 - 转换PDF 2/3..."
}
```

## 规则

### 1、被禁止的行为

（1）禁止修改或删除原始上传的资料文件
（2）禁止跨患者混淆资料（不同患者不能共用文件夹）
（3）禁止将未转换的PDF直接传递给下游Skill
（4）禁止覆盖已有患者文件夹中的现有内容

### 2、约束条件

（1）患者文件夹命名必须遵循 `{患者姓名}_{门诊号}` 格式
（2）就诊时间文件夹命名必须使用标准日期格式 `YYYY-MM-DD`
（3）资料类型子文件夹必须使用5种标准类型名称
（4）患者—AI医生对应关系表必须保持最新
（5）MD转换后必须保留原始PDF文件作为备份

### 3、鼓励的行为

（1）在日志中详细记录每个操作步骤及耗时
（2）对于批量PDF转换，使用并行处理提升效率
（3）转换过程中校验MD文件的完整性（标题、段落结构）
（4）遇到同名文件时使用时间戳后缀命名避免冲突
