# Skill 02 测试新增经验

1. **影像报告全为图片型PDF**：所有34个影像报告（CT/MRI/PET-CT）均为1页截图，pypdfium2无法提取文本。
   处理方案：引入OCR处理，可使用 `folder-rag` 或 `pdf-ocr` 技能的EasyOCR能力。
   
2. **检验报告为合并多日期PDF**：3个检验报告PDF文件包含多个日期的检验数据，需按页/按检查日期拆分到各就诊周期。
   
3. **80个PDF转换耗时约2分钟**：使用pypdfium2逐页处理，平均每个PDF约1.5秒。
   大数据量时可考虑并行处理优化。

4. **患者编号冲突**：住院病历号（0000836961）与日间化疗病历号（0008156703）不一致。
   患者信息表设计应支持多病历号关联。

5. **MD文件内容验证**：随机抽查3个MD文件，内容完整、格式正确。
