# 报告格式转换

使用fpdf2 + Windows中文字体将问诊结果转换为PDF报告。

## 系统要求
- Python包：fpdf2（已安装）
- 中文字体：Windows系统自带（simhei.ttf / simsun.ttc / simkai.ttf / simfang.ttf）
- 字体路径：`C:\Windows\Fonts\`

## 执行流程

### 1、输入
（1）完整的问诊结构化数据（MD格式或JSON格式）
（2）模板结构（见下方模板定义）
（3）输出文件路径

### 2、步骤说明

#### 步骤1：准备报告内容数据
收集以下模块的最终输出（医生编辑后的版本）：
- 患者病史（编辑后）
- 患者概况（编辑后）
- 治疗方案（选定/编辑后）
- 疗效预测（重新预测后）
- 其他建议（编辑后）

#### 步骤2：调用PDF生成脚本
使用 `exec` 工具执行Python脚本生成PDF：

```bash
python "skills/肺癌医生Agent/scripts/generate_report_pdf.py" \
  --input "问诊报告张三.md" \
  --output "\\Steven\Agent\智能体\开发任务\医生Agent\案例\AI问诊报告张三.pdf" \
  --patient "张三" \
  --clinic-id "0008156703" \
  --visit-date "2026-05-30"
```

#### 步骤3：PDF输出规则
- 文件名格式：`{姓名}-{门诊号}-{就诊日期}-AI门诊报告.pdf`
- 保存到指定输出路径
- 最后一页添加AI声明

### 3、报告模板结构

报告中各章节按以下顺序排列：

```
1. 标题页
   - AI门诊报告
   - 患者姓名 | 门诊号 | 就诊日期

2. 基本信息
   - 姓名、性别、年龄、门诊号、就诊日期

3. 主诉

4. 现病史（含疗效检测曲线、不良反应热力图、预后曲线）

5. 既往史

6. 过敏史

7. 个人史

8. 体格检查

9. 辅助检查（含影像报告摘要、病理报告摘要、检验报告摘要）

10. AI肿瘤负荷评估（TNM分期）

11. AI肿瘤疗效评估（附趋势图）

12. AI不良反应评估

13. AI诊断（肿瘤诊断 + 不良反应诊断 + 合并症诊断）

14. AI建议（含治疗方案、疗效预测、康复建议，附多维权重图）

15. 门诊医生建议

16. 声明页
    "本报告由AI辅助生成，仅供医生参考，不能替代正式医疗文书或面诊意见。"
    "质控审查人：_________"
```

### 4、PDF格式规范

| 元素 | 字体 | 字号 | 样式 |
|------|------|------|------|
| 标题 | 黑体 (simhei.ttf) | 18pt | 加粗 |
| 章节标题 | 黑体 | 14pt | 加粗 |
| 正文 | 宋体 (simsun.ttc) | 10pt | 常规 |
| 表格 | 宋体 | 9pt | 常规 |
| 页脚 | 宋体 | 8pt | 常规 |
| 声明 | 楷体 (simkai.ttf) | 9pt | 斜体 |

### 5、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 字体文件未找到 | 尝试其他中文字体路径 |
| 输入数据格式不正确 | 校验JSON/MD格式，提示修正 |
| fpdf2未安装 | pip install fpdf2 |
| 输出目录不存在 | 自动创建目录 |

## 工具声明（tools）

### 1、可以使用的工具

| 工具名称 | 说明 | 适用场景 |
|----------|------|----------|
| exec | 执行Python脚本 | 调用PDF生成脚本 |
| read | 读取输入MD文件 | 获取报告内容 |
| write | 写入临时数据文件 | 准备生成脚本输入 |

### 2、不可使用的工具
（1）禁止在不校验内容的情况下直接生成PDF
（2）禁止使用不支持中文的PDF库
