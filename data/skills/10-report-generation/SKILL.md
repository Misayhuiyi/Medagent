# 生成报告

肺癌医生Agent应用层第10个Skill（最终步骤）。将完整的问诊结果输出为PDF格式的AI门诊报告。

## 执行流程

### 1、输入
（1）医生编辑完善后的完整问诊结果

### 2、步骤说明

#### 步骤1：合并所有问诊结果

收集以下前序步骤的全部输出（`previous_results` 中的 05-09）：
- 患者病史（05-患者病史总结的输出）
- 患者概况（06-患者概况的输出）
- 治疗方案（07-治疗方案的输出）
- 疗效预测（08-疗效预测的输出）
- 其他建议（09-其他建议的输出）

#### 步骤2：添加声明
- 报告尾页添加声明：本报告由AI辅助生成，仅供医生参考，不能替代正式医疗文书或面诊意见。质控审查人：医生

#### 步骤3：输出结构化报告
- 按以下模板结构组织输出 JSON
- 包含所有前序步骤的关键字段
- 声明内容附加在 report 末尾

### 3、输出

输出完整报告 JSON（包含所有前序步骤的关键数据）：

```json
{
  "report": {
    "patient_history": "（05-病史总结的完整输出）",
    "patient_profile": "（06-患者概况的完整输出）",
    "treatment_plan": "（07-治疗方案的完整输出）",
    "efficacy_prediction": "（08-疗效预测的完整输出）",
    "suggestions": "（09-其他建议的完整输出）"
  },
  "disclaimer": "本报告由AI辅助生成，仅供医生参考，不能替代正式医疗文书或面诊意见。质控审查人：医生"
}
```
