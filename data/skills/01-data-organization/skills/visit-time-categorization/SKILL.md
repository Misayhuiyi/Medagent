# 就诊时间归类

资料整理主Skill的子Skill之一。负责按就诊时间对患者资料文件进行归类。

## 执行流程

### 1、输入
（1）患者资料文件列表（含文件名、文件路径、文件修改时间）
（2）可选：已知的入院/出院记录日期列表

### 2、步骤说明

#### 步骤1：文件名日期解析（分层匹配）
按优先级依次尝试以下规则从文件名提取日期：

**第一优先级：YYYYMMDD格式**（8位数字）
- 正则：`(\d{8})` 
- 示例：`20231205003404v2.pdf` → 提取 `2023-12-05`
- 解析规则：前4位=年，中间2位=月，最后2位=日

**第二优先级：YYMMDD格式**（6位数字，且以"20""21""22""23""24""25"等年份前缀开头）
- 正则：`(\d{6})`
- 示例：`231205入院记录.pdf` → 提取 `2023-12-05`
- 解析规则：加"20"前缀，然后前2位=年，中间2位=月，最后2位=日
- ⚠️ 注意：必须检查年份是否合理（2020-2030），不合理则跳过

**第三优先级：文件名中包含明确日期文本**
- 如"2023年12月5日"、"2023-12-05"等

**第四优先级：文件修改时间**
- 使用操作系统文件修改时间作为最后备选

#### 步骤2：就诊时间归约
以入院记录→出院记录确定住院周期，归约规则如下：

**规则A**：有入院记录和出院记录 → 以入院日期~出院日期为一个住院周期
- 该周期内的影像报告、病理报告、检验报告均归入此周期
- 周期标签：出院日期

**规则B**：只有入院记录无对应出院记录 → 以入院日期为起点
- 后续一周内的文件归入此周期

**规则C**：门诊记录 → 按门诊日期单独记录

**规则D**：独立的检查报告/病理报告（无对应病历） → 按检查日期单独记录

#### 步骤3：输出结果
（1）按时间排序的就诊周期列表
（2）每个周期内按5种资料类型分类的文件列表
（3）输出格式：JSON结构化数据

## 条件判断

| 条件 | 处理方式 |
|------|----------|
| 文件名含YYYYMMDD | 优先使用，直接解析 |
| 文件名含YYMMDD | 加20前缀解析，验证年份合理性 |
| 文件名无数字日期 | 用文件修改时间 |
| getReportSnaphotPath模式文件名 | 用文件修改时间 |
| 多文件同一天 | 合并到同一天分组 |

## 错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 日期解析异常 | 记录异常信息，尝试下一优先级规则 |
| 解析出的日期不合理（年份<2020或>2030） | 跳到下一优先级 |
| 所有规则都解析失败 | 使用文件修改时间，在日志中注明 |

## 输出
（1）就诊时间分组JSON
（2）日期解析日志
