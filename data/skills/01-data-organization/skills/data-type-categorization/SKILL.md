# 资料类型归类

资料整理主Skill的子Skill之一。负责按标准资料类型对已按就诊时间分组的文件进行分类。

## 执行流程

1. **输入**：已按就诊时间分组的文件列表
2. **类型识别**：根据文件名和文件内容分类：
   - **影像报告**：包含"CT"、"MRI"、"PET-CT"、"X光"、"超声"、"影像"等关键词
   - **病理报告**：包含"病理"、"活检"、"免疫组化"、"IHC"、"基因检测报告"等关键词（仅组织病理，不包含液体活检的基因检测）
   - **检验报告**：包含"血常规"、"肝功"、"肾功"、"肿瘤标志物"、"基因检测"等关键词（液体活检的基因检测归入此）
   - **病历**：包含"入院记录"、"门诊记录"、"病历"等关键词
   - **医生诊疗**：包含"出院记录"、"出院小结"、"诊疗"等关键词
3. **分组输出**：每个就诊时间下按5种类型输出
4. **特殊处理**：
   - 入院记录和门诊记录 → "病历"文件夹
   - 出院记录 → "医生诊疗"文件夹

## 错误处理

- 类型无法识别 → 标记为"未分类"，通知用户手动归类
- 同文件可属于多类型 → 按最匹配类型归类，备注其他可能性
