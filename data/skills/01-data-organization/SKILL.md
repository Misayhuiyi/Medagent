# 资料整理

肺癌医生Agent应用层的第一个执行步骤。负责将患者上传的检查资料按时间顺序和资料类型进行分类整理，为后续AI问诊提供结构化的输入数据。

## 执行流程

### 1、标准的输入

（1）患者上传的资料文件列表（含文件路径、文件名、文件类型、文件修改时间）
（2）患者基本信息（姓名、门诊号）
（3）可选：既往已经整理的资料目录结构

### 2、步骤说明

#### 步骤1：子Agent调用子Skill「就诊时间归类」
创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/visit-time-categorization/SKILL.md`：
- 读取所有资料文件的修改时间或文件名中的时间信息
- 按就诊时间（门诊/住院时间）归类
- 如果有多条就诊记录，按时间先后排序分组
- 输出：时间分组后的资料文件列表

#### 步骤2：子Agent调用子Skill「资料类型归类」
创建子Agent（`sessions_spawn`，`context="isolated"`）调用子Skill `skills/data-type-categorization/SKILL.md`：
- 在每个时间分组内，按以下5种类型分类：
  - **影像报告**：CT、MRI、PET-CT、X光等影像学检查报告
  - **病理报告**：穿刺活检、手术病理、免疫组化等病理学报告
  - **检验报告**：血常规、肿瘤标志物、基因检测等实验室检查报告
  - **病历**：入院记录、门诊记录（存放在此）
  - **医生诊疗**：出院记录（存放在此）
- 输出：按时间→类型两层分类的结构化目录

#### 步骤3：输出整理结果
- 将整理后的目录结构保存到指定路径
- 输出结果到标准输出，供下一个Skill（资料预处理）使用

### 3、条件判断

| 条件 | 处理方式 |
|------|----------|
| 只有一个就诊时间 | 直接在该时间下按类型分类 |
| 多个就诊时间 | 按时间排序，每个时间独立分类 |
| 文件时间信息不明确 | 使用文件修改时间作为就诊时间 |
| 某类型无资料 | 该类型目录可以为空，但不能缺失 |

### 4、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 未找到任何资料文件 | 输出「无资料需整理」错误信息，通知用户上传资料 |
| 文件无法读取或损坏 | 跳过该文件，在整理结果中标记为「无法读取」 |
| 文件类型无法识别 | 归类到「其他」类型，通知用户手动处理 |

### 5、规范的输出

（1）结构化资料目录（JSON格式）：
```json
{
  "就诊时间1": {
    "影像报告": ["文件1", "文件2"],
    "病理报告": ["文件3"],
    "检验报告": ["文件4", "文件5"],
    "病历": ["文件6"],
    "医生诊疗": []
  },
  "就诊时间2": { ... }
}
```
（2）整理日志（记录归类依据和异常情况）

## 规则

### 1、被禁止的行为

（1）禁止修改或删除原始文件
（2）禁止在未分类的情况下将文件直接传递给下一阶段
（3）禁止合并不同就诊时间的资料

### 2、约束条件

（1）必须严格按"就诊时间→资料类型"两层结构组织
（2）资料类型分类必须严格对应5种标准类型
（3）入院记录和门诊记录统一归入"病历"类
（4）出院记录统一归入"医生诊疗"类

### 3、鼓励的行为

（1）对于有明确时间标注的文件，优先使用标注时间而非文件修改时间
（2）在整理日志中记录无法归类的文件及其原因
（3）对于同一就诊时间的连续日期范围，合理合并为一个就诊时间段
