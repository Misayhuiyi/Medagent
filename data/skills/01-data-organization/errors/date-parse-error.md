# 就诊时间归类：日期格式解析错误

## 现象
YYYYMMDD格式的文件名（如`20231205...`）被错误解析为年份20XX的错误日期。

## 原因分析
原先使用 `(\d{6})` 匹配前6位数字，错误地将 `202312` 解析为 年=20 月=23 日=12。

## 修复方案
1. 优先使用 `(\d{8})` 匹配8位日期格式
2. 若匹配到8位数字 → 直接按 YYYY-MM-DD 解析
3. 若匹配到6位数字 → 加"20"前缀后解析
4. 文件名中有明确日期文本时优先使用
