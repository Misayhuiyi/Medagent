# 过敏史

肺癌医生Agent患者病史总结流程的子Skill。负责从病历、出院记录、AI问诊记录中提取患者的过敏信息，去重合并后输出。

## 执行流程

### 1、标准的输入

（1）所有就诊时间的MD文件路径列表（重点：病历、医生诊疗文件夹）
（2）既往AI问诊输出记录路径列表（如有）

### 2、步骤说明

#### 步骤1：信息提取

- 从病历（入院记录）的「过敏史」章节提取
- 从AI问诊记录中提取过敏信息
- 从用药记录中推断可能的过敏（如病历中提及「因过敏停用XXX」）
- 提取关键字段：过敏源名称、过敏类型（药物/食物/其他）、反应表现、严重程度

#### 步骤2：去重合并

- 相同过敏源只保留一次
- 不同来源的相同过敏源信息合并
- 如果同一过敏源在不同来源中描述不同，保留最详细的版本

#### 步骤3：荟萃输出

- 过敏源列表（含类型、反应、严重程度）
- 过敏史总结（一句话概括）
- 标注「无过敏史」或「未提及」

### 3、条件判断

| 条件 | 处理方式 |
|------|----------|
| 明确标注「无过敏史」| 输出「无过敏史」|
| 未提及过敏史 | 标记为「未提及」|
| 有明确过敏记录 | 列出所有过敏源 |
| 过敏反应描述模糊 | 记录已知信息，标记「反应程度不详」|

### 4、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 过敏史章节不存在 | 从全文搜索过敏相关关键词 |
| 过敏源名称不标准 | 使用标准药品名称/食物名称替换 |
| 严重程度未说明 | 根据描述推断（如仅是皮疹→轻度）|

### 5、规范的输出

```json
{
  "summary": "患者有青霉素过敏史（皮疹），无其他过敏史",
  "details": [
    {
      "allergen": "青霉素",
      "type": "药物过敏",
      "reaction": "皮疹（全身散在红色斑丘疹）",
      "severity": "轻度（1级）",
      "occurrenceTime": "不详",
      "source": "入院记录"
    }
  ],
  "noKnownAllergy": false,
  "notMentioned": false
}
```

## 规则

### 1、被禁止的行为

（1）禁止将药物不良反应混淆为过敏反应
（2）禁止在无依据的情况下推断过敏源

### 2、约束条件

（1）过敏源必须标注类型（药物/食物/其他）
（2）反应表现必须有描述
（3）严重程度必须有分级

### 3、鼓励的行为

（1）关注化疗/靶向药物相关的已知过敏风险
（2）区分真正的过敏反应与药物副作用
