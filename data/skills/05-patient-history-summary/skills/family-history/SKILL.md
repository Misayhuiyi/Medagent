# 家族史

肺癌医生Agent患者病史总结流程的子Skill。负责从病历、问诊记录中提取患者的家族疾病史信息，重点关注肺癌相关家族史和遗传倾向。

## 执行流程

### 1、标准的输入

（1）所有就诊时间的MD文件路径列表（重点：病历）
（2）既往AI问诊输出记录路径列表（如有）

### 2、步骤说明

#### 步骤1：信息提取

- 从病历（入院记录）的「家族史」章节提取
- 从AI问诊记录中提取家族史
- 提取内容包括：

##### 恶性肿瘤家族史（重点关注）
- 直系亲属（父母、兄弟姐妹、子女）的恶性肿瘤史
- 旁系亲属（祖父母、叔伯姑舅姨）的恶性肿瘤史
- 重点关注：肺癌、乳腺癌、结直肠癌等
- 患病年龄和诊断情况

##### 遗传性疾病家族史
- 遗传性肿瘤综合征相关基因突变（如EGFR、BRCA、RET等）
- 其他遗传性疾病

##### 其他家族性疾病
- 高血压、糖尿病等慢性病家族史（如相关）

#### 步骤2：血缘关系分级

- 一级亲属：父母、兄弟姐妹、子女
- 二级亲属：祖父母、外祖父母、叔伯姑舅姨
- 三级亲属：堂表兄弟姐妹

#### 步骤3：去重合并并输出

- 相同亲属的疾病信息合并
- 结构化输出

### 3、条件判断

| 条件 | 处理方式 |
|------|----------|
| 明确标注「无恶性肿瘤家族史」| 记录为「无」|
| 未提及家族史 | 标记为「未提及」|
| 家族中多人患癌 | 全部列出，标注与患者的关系 |
| 亲属患癌年龄不详 | 记录「年龄不详」|

### 4、错误处理

| 错误类型 | 处理方案 |
|----------|----------|
| 家族史章节不存在 | 从AI问诊记录提取或标记为「未记录」|
| 亲属关系描述模糊（如"亲戚"）| 记录为「具体关系不详的亲属」|
| 疾病名称不标准 | 使用标准医学诊断名称替换 |

### 5、规范的输出

```json
{
  "summary": "患者父亲因肺癌去世（70岁），母亲健在，否认其他恶性肿瘤家族史",
  "malignancyHistory": [
    {
      "relation": "父亲",
      "relationshipLevel": "一级亲属",
      "disease": "肺癌",
      "ageAtDiagnosis": 68,
      "ageAtDeath": 70,
      "smokingHistory": "吸烟",
      "notes": "病理类型不详"
    }
  ],
  "geneticHistory": {
    "knownMutations": [],
    "syndromes": []
  },
  "otherFamilyDiseases": [
    {"relation": "母亲", "disease": "高血压", "diagnosisTime": "不详"}
  ],
  "noMalignancyHistory": false,
  "notMentioned": false
}
```

## 规则

### 1、被禁止的行为

（1）禁止在无依据的情况下添加家族史信息
（2）禁止将家族史与患者个人史混淆

### 2、约束条件

（1）必须标注亲属关系等级（一/二/三级）
（2）恶性肿瘤家族史必须标注患病年龄（如已知）
（3）未提及家族史时标记「未提及」，不可默认为「无」

### 3、鼓励的行为

（1）关注肺癌相关的家族聚集性现象
（2）如家族中有多名亲属患癌，提示遗传性肿瘤综合征可能
（3）注意亲属吸烟史对肺癌家族倾向的影响
